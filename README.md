# 晋阳的同人库

一个纯前端 SillyTavern 扩展。它会读取当前角色卡、聊天上下文以及实际启用的世界书条目，核对同人角色与原作时间线，并把精简资料持久同步到角色绑定的世界书。

正常生成会立即放行，不在正文生成前调用分析或搜索 API，也不会把人物表当成登场清单或剧情提纲。用户可以手动核验最新输入中明确点名的新对象；候选译名只作为线索，搜索结果可以校正正式姓名和所属作品。核实后的资料会写入本卡资料库，再由分析模型压缩成“按当前时间线过滤”的紧凑档案。已有角色直接复用缓存，只有明确 AU 差异或重大时间线变化才做增量更新。

每次正文生成后，插件会在后台用一次分析请求同时更新场景状态与执行 OOC 审核。自动识别的“当前人物/地点”是当前场景快照：人物进场时增加，明确离场或切换场景后移除；用户手动添加的固定项始终保留。离场人物的原作档案不会删除，只是不再列为当前在场，日后回归可以直接复用。作品、时间线和时间节点只在正文明确发生切换时替换，分析模型不得自行推进剧情。

当前场景会写入一个独立、常驻且覆盖更新的世界书条目，包含当前作品、时间线、在场人物、地点和已发生状态；它与按角色分别保存的原作基础档案互不混合。消息接收、渲染完成和生成结束都会触发同一条去重同步队列，刷新、升级、切换聊天及后台巡检还会补跑遗漏。分析或世界书写入失败时会自动退避重试，并在设置页显示可核对的同步状态。

若正文含有 `NE-BANNER` 场景横幅，插件会把横幅中的人物、地点和时段作为已生成正文的确定事实，覆盖分析模型残留的上一场景候选项；横幅不会被当作原作资料，也不会自行推进剧情。

用户人物和明确标记的原创人物不会通过原作档案别名进行映射。若旧版本曾把用户名字误收进某个原作角色的别名，插件会在场景同步时自动清除并更新对应世界书关键词。

新原作角色第一次出现在正文后，插件会立即在后台检索并建立独立档案；资料写入后会自动再次审核刚才的正文，因此首次出现时漏掉的正式姓名、外貌或性格冲突也能被补充修正。

手动核验不会对同一轮上下文重复规划联网检索；重试或重生成得到新正文后，只重新计算生成后的当前场景快照与 OOC 审核，不会在正文生成前增加等待。

“重置本局全部资料”只清理当前角色卡的当前聊天、插件世界书条目和运行时注入，不会清空其他角色卡资料或共享搜索缓存；全局缓存由独立的“清空缓存”按钮管理。

正文生成完毕后，插件会把刚生成的消息与本卡资料档案交给分析模型审核：凡是与档案冲突、且角色卡、用户指示、已确认 AU 差异和此前剧情都没有解释过的内容（姓名译名、年龄身份、外貌、性格行为、能力、经历、人际关系和时间线事实等），会按最短冲突片段修订并更新消息。审核只处理正文中实际出现的已有档案角色，不得改变剧情走向、登场角色、行动结果或场景顺序；修订记录会显示在插件报告里。

已有角色不会重复搜索或重新总结。新 AU 差异直接增量追加到对应角色；只有实际跨越重大原作时间线、确实需要补充官方事实时才联网查询，并且世界书内容逐字段确认有变化后才会写入。

免费 Wiki 模式会先把分析模型产生的长检索词压缩为“人物/实体 + 作品名”，空结果不会缓存，避免一次临时失败造成长时间无法重试。

界面会根据当前视口和输入设备自动适配：桌面保持多列宽屏布局，手机竖屏切换为单列触控布局，手机横屏和平板使用双列紧凑布局，并兼容安全区域与动态视口高度。

## 安装

1. 打开 SillyTavern 的“扩展”面板。
2. 点击“安装扩展”。
3. 粘贴本仓库的 Git URL 并安装。
4. 刷新页面，从输入框旁的扩展菜单打开“晋阳的同人库”。

安装地址：`https://github.com/jiny75559-gif/-.git`

仓库根目录就是扩展目录，无需修改 SillyTavern 服务端源码。

## 每位用户独立配置 API

- Wiki 模式免费且无需 Key。
- Tavily、Serper、SerpApi 使用 SillyTavern 自带的用户密钥库。
- 自定义搜索 AI（Grok、OpenAI 兼容中转等）和独立分析 LLM 的 Key 只保存在当前浏览器的 `localStorage`，并按 SillyTavern 用户账号隔离。
- Key 不会写入角色卡、世界书、聊天、扩展设置或 Git 仓库。
- 换手机、电脑或浏览器后，需要在新设备重新填写 Key。

## 自定义 API 要求

自定义 API 应兼容以下端点：

- `GET /v1/models`
- 分析：`POST /v1/chat/completions`
- 联网搜索：`POST /v1/responses` 并支持 `web_search`，或提供自身具备联网能力的 `POST /v1/chat/completions`

插件优先由浏览器直连 API；模型列表、分析请求及 Chat Completions 搜索在跨域受限时会自动使用 SillyTavern 自带的通用代理，仍不需要修改服务端源码。Responses API 联网搜索必须使用 HTTPS，并允许浏览器跨域访问（CORS）。

## 隐私与安全

浏览器本地存储可防止 Key 被发布或混入酒馆数据，但同源网页脚本理论上能够访问它。请只安装可信的 SillyTavern 扩展，使用权限受限的独立 Key，并定期轮换。设置页提供“删除此设备 Key”按钮。

## 更新

扩展启用了 `auto_update`。通过 Git URL 安装后，可以使用 SillyTavern 的扩展更新功能获取新版本。

每次版本更新后，酒馆会自动弹出一次本版更新内容；插件设置页顶部也会常驻显示当前版本日志。完整历史见 [CHANGELOG.md](CHANGELOG.md)。
